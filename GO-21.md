# GO-21 — Ship the RAG knowledge-store chat (build plan)

> A deployed, one-command-runnable RAG chatbot that can be pointed at any document corpus and answer questions over it with citations.
> Milestone-ordered (M-letters), not calendar-dated — sequencing only. Each milestone has a "done when" and a demoable checkpoint.

## Stack decision (grounded in 2026 research)

| Layer | Choice | Why |
|-------|--------|-----|
| Runtime | **NestJS (Node/TypeScript)** | Mainstream Node/TS stack — fast to build, production-grade. |
| Vector store | **Postgres + pgvector (HNSW index)** | The "underrated correct answer" for 1–10M vectors; no extra service, transactional, standard SQL tooling integrators already have. |
| Embeddings | **Voyage (default `voyage-4-lite`, env `VOYAGE_MODEL`) behind a swappable adapter** | Anthropic-ecosystem embedding recommendation; the adapter interface lets an integrator swap OpenAI/local without touching call sites — no vendor lock-in. |
| Generation | **Claude `claude-opus-4-8` via `@anthropic-ai/sdk`** | Latest model; use the **native citations** feature (`citations: {enabled: true}` on document blocks) so answers are grounded with source spans — the product's core trust feature. |
| Packaging | **Docker Compose** (app + Postgres/pgvector) | One-command run so anyone can plug in their documents and run it. |

Keep it lean — **no LangChain/LlamaIndex**. A thin retrieval layer over pgvector + the Anthropic SDK keeps full ownership of the pipeline — easier to reason about, debug, and tune against the eval harness than a framework.

## What sets the quality bar

Fold these in as you go — they're cheap and they're what make it production-grade:
- **Structured logging** on the ingest + query paths.
- **The eval harness (GO-21g)** — a quantitative retrieval-quality number; the objective quality gate that catches regressions when tuning. Put it in the README.
- **Swappable adapters** for embeddings and vector store (interface + one alt implementation) — no vendor lock-in.
- **Env-config + Docker** — runs anywhere with one command.
